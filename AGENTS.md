# Notes for coding agents

- Development setup, tests and formatting: [docs/development.md](docs/development.md).
- Desktop, input and packaging changes also need VM checks. Before using the
  VMs, read [docs/vm-testing.md](docs/vm-testing.md), especially
  [Parallel testing by agents](docs/vm-testing.md#parallel-testing-by-agents):
  one worktree per change, and lock each VM before touching it.
- Do not push, open pull requests or comment on GitHub unless asked.
